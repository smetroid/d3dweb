// features

Everything you need. Nothing you don't.

Built for engineers who think in graphs — pipelines, workflows, dependency trees, service maps. Ships as a single Vite build.

Live presence

Colored halos on every peer's selection. Avatar chips in the HUD. All multiplexed through one WebSocket per diagram.

Time travel

Shift+H opens the history drawer. Restore any of the last 50 snapshots — peers reload instantly.

Signed share links

Mint a JWT with Shift+S. Recipients hit /join/:token. Revoke anytime, server-side.

Keyboard-first · rebindable

hjkl nav, e edit, n/d add node/edge, ⌘K command palette, f hints. Every default is rebindable.

Eight layouts, one keystroke

Cola, CoSE, Dagre, Breadth-First, Grid, Circle, Concentric, Random — swap live with ⌘+1..8. Persists per diagram.

Anonymous guests

View-only visitors get a server-generated name ("Teal Fox"). No sign-up. No PII. Persisted per share in localStorage.

// quick start

Running in 60 seconds.

Clone, install, point at a local d3d-api, and you're live. Real-time collab is one env var away.

Full setup guide →
~ / projects / d3dweb
# clone and install
$ git clone github.com/smetroid/d3dweb
$ cd d3dweb && npm install
 
# enable collab
$ echo "VITE_COLLAB_ENABLED=true" > .env.local
 
# fire it up
$ npm run dev
➜ Local: http://localhost:5173/
➜ ready in 412 ms

// architecture

Boring stack. Sharp edges.

Vue 3 Options API, Cytoscape.js core, native WebSocket. No Yjs runtime tax. No Redis to babysit. The API owns identity, storage, and fan-out — the client just renders and emits.
